ZCnova — SRIハッシュ取得ツール

ZCnova BGM Studio が外部から読んでいる2つのファイルのハッシュ値を取得します。
このファイルをブラウザで開いて、下のボタンを押すだけです。

使い方

  1. 下の「ハッシュを取得する」を押す
  2. 結果をコピーして、そのまま渡す（またはHTMLに貼る）
ネットにつながっている環境で開いてください。 ファイルをダブルクリックで開くと失敗する場合があります （ブラウザの制限）。その場合は ZCnova を置いているサイトと同じ場所に このファイルを置いて、https://…/sri-hash-tool.html として開いてください。

方法A：Webサービスを使う
https://www.srihash.org/ を開き、下のURLを1つずつ貼って 「Hash!」を押すと、貼り付け用のタグがそのまま出ます。 
https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js
https://cdn.jsdelivr.net/npm/lamejs@1.2.1/lame.min.js
方法B：Mac / Linux のターミナル 
for u in \
  https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js \
  https://cdn.jsdelivr.net/npm/lamejs@1.2.1/lame.min.js ; do
  echo "$u"
  echo "  sha384-$(curl -sL "$u" | openssl dgst -sha384 -binary | openssl base64 -A)"
done
方法C：Windows の PowerShell 
@(
 "https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js",
 "https://cdn.jsdelivr.net/npm/lamejs@1.2.1/lame.min.js"
) | ForEach-Object {
  $b = (Invoke-WebRequest $_ -UseBasicParsing).Content
  if ($b -is [string]) { $b = [Text.Encoding]::UTF8.GetBytes($b) }
  $h = [Security.Cryptography.SHA384]::Create().ComputeHash($b)
  "$_`n  sha384-$([Convert]::ToBase64String($h))"
}
